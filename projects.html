Prostate Cancer Histopathology Classification — PANDA Dataset

Computer Vision · CNN · ViT-B/16 · GCViT-Tiny · PyTorch
Computer Vision Vision Transformers Grad-CAM PyTorch
  • Built a reproducible image-classification pipeline on 10,616 histopathology images using stratified train, validation and test splits to prevent data leakage.
  • Benchmarked a CNN, Vision Transformer (ViT-B/16) and GCViT-Tiny under controlled experimental settings.
  • Mitigated class imbalance and overfitting with class-weighted cross-entropy, label smoothing, OneCycleLR scheduling and early stopping; used mixed-precision training for GPU efficiency.
  • Achieved test accuracy of 0.7872 (CNN) and 0.7994 (ViT-B/16); evaluated multiclass performance with macro F1, confusion matrices and quadratic weighted kappa.
  • Applied Grad-CAM to audit which image regions drove predictions, validating model reasoning and interpretability.

Adaptive Anomaly-Based Intrusion and Ransomware Detection Framework

Unsupervised Learning · Ensemble Learning · CICIDS2017 · UNSW-NB15 · scikit-learn
Anomaly Detection Ensemble Learning Cybersecurity Analytics scikit-learn
  • Designed a lightweight unsupervised ensemble combining Isolation Forest, Local Outlier Factor and One-Class SVM with adaptive thresholding.
  • Developed end-to-end preprocessing, training and evaluation workflows across network-intrusion and ransomware datasets.
  • Recorded 0.99924 accuracy with random forest on CICIDS2017 and 0.9958 with logistic regression on UNSW-NB15, and scrutinised near-perfect scores for leakage and dataset bias.
  • Evaluated true generalisation with leave-family-out testing, achieving 0.8909 macro accuracy across unseen ransomware families.
  • Assessed robustness and operational trade-offs using classification reports, ROC analysis, confusion matrices and comparative experiments.
